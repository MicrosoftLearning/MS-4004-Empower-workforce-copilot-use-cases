# Exercise 2, Task 3: Use Microsoft Copilot's Idea Coach agent to generate creative campaign concepts
---
Now that you have finished analyzing the market data and reviewing the performance of Mystic Spice Premium Chai Tea, you want to develop ideas for a new seasonal marketing campaign that builds on the brand's growing success. The campaign should target health-conscious, experience-driven consumers who value comfort, wellness, and authenticity—the core brand pillars of Mystic Spice Premium Chai Tea.

Perform the following steps to complete this task:

1. Open **Microsoft Copilot**, and in the navigation pane, select **Agents**. In the **Agent Store**, under the **Your agents** section, select **See more** to view all your agents. In the expanded list of **Your agents**, select **Idea Coach**.

2. In the **Idea Coach** prompt box, attach the **Mystic Spice Premium Chai Tea product description.docx** file that you downloaded in Task 1 and stored in OneDrive. Then, ask the Idea Coach agent to review the attached product description file and generate 3–5 marketing campaign ideas that align with the warm, comforting identity of Mystic Spice Premium Chai Tea.

3. Review the campaign ideas and then select one that appeals to you. You will use this campaign idea through the rest of this task and in the next one.

4. Once you select a campaign idea, ask the Idea Coach agent to expand on this campaign idea with suggestions for key messages, taglines, and promotional activities (for example, influencer collaborations, social media themes, in-store experiences).

5. Your ultimate goal is to create a Word document that contains not only this response but also various other ideas that you will ask Idea Coach to generate about your selected campaign in the upcoming steps. Although creating documents is outside the role of Idea Coach, you can edit its responses in **Pages** and then save them as a Word document or PDF.
    
   Since you want to eventually save this content to a Word document, select the ellipsis **(...)** next to the response, then select the **Edit in Pages** option from the menu.

6. When you select **Edit in Pages**, Microsoft Copilot displays two panes: one containing the **Idea Coach** agent and your current chat, and another containing the **Pages** form and the content copied from your chat.
    
   Review the content in the **Pages** form. Delete any extraneous text that was copied and pasted with the results (see the beginning and end of the content). Feel free to change the headings or any other content in the form.

7. In the **Idea Coach** chat pane, ask it to refine the ideas for your selected campaign for the Latin American market and for Gen Z and professional demographics.

8. Review the response. To include it with the existing content in the Pages form, select the ellipsis **(...)** next to the response, and then select **+ Add to page**. Scroll to the bottom of the **Pages** form and verify that the content was inserted. Delete any extraneous text that was copied and pasted with the content (see the beginning and end of the content pasted into the Pages form).

9. Review the suggested prompts that the agent displayed at the end of its last response. Select and submit a prompt that interests you.

   > [!CAUTION]
   > Be wary of prompts that ask you to generate content in a foreign language. The agent might return that response and continue responding in that language in subsequent turns. If this occurs, ask the agent to continue in your preferred language. If the agent continues responding in the foreign language, start a new chat to reset the conversation context.
    
   If none of the prompts interest you, ask the agent to generate more suggested prompts. You must then select a prompt and copy and paste it into the prompt field.
    
10. Add this response to the **Pages** form, just as you did with the prior response.

11. You're now ready to save the content from Pages as a Word document. In the **Pages** pane, select the ellipsis (**...**) at the top right of the form. In the menu that appears, select **Export** > **Document**. This option instructs the agent to generate a draft of the content for **Microsoft Word**.

12. Once the agent finishes generating the draft, select the **Open Word** button that appears. This opens a new browser tab containing a document in **Word for the web**. The content from the **Pages** form should appear in the Word document. Save the document to OneDrive as **Mystic Spice Premium Chai Tea campaign concepts.docx**.

13. You plan to use the **Mystic Spice Premium Chai Tea campaign concepts** document in the next task.
